## 🎯 本次更新有什么新内容？

### ✨ 新功能：调试模式

现在您可以启用调试模式，当应用出现问题时会显示详细的错误信息！

**如何使用**:
1. 打开应用
2. 点击右上角齿轮图标打开设置
3. 向下滚动到底部，找到"**开发者**"部分
4. 打开"**调试模式**"开关
5. 完成！现在如果应用遇到错误，会显示详细信息

**为什么有用**:
- 🐛 遇到问题时能看到具体错误信息
- 📋 错误可以复制并分享给开发者
- 🔧 帮助诊断问题原因
- 📝 详细的技术细节便于故障排查

### 🔍 问题改进追踪

我们识别了首曲播放有时卡顿的原因，并设计了解决方案。下个版本将进一步优化这个问题。

## ❓ 常见问题

### Q: 启用调试模式会影响应用性能吗？
**A**: 不会。调试模式在应用出现异常时才会显示信息，日常使用没有性能影响。

### Q: 错误信息是否会上传到云端？
**A**: 不会。所有错误信息仅保存在您的设备上，不会自动上传任何地方。您可以完全控制是否分享信息。

### Q: 我在日常使用时需要打开调试模式吗？
**A**: 不需要。调试模式主要用于故障排查。日常使用时可以关闭。

### Q: 如何关闭调试模式？
**A**: 打开设置，找到"开发者"部分，关闭"调试模式"开关即可。

### Q: 调试模式有什么风险吗？
**A**: 没有。调试模式仅在应用遇到错误时显示信息，不会影响任何其他功能。

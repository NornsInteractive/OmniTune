## 🎨 UI 重构的优先级

### 🔴 **最高优先级** - 播放器界面
这是用户最常互动的界面，重新设计将有最大影响。

**计划改动**:
```
当前布局:                          新布局:
┌─────────────────┐              ┌─────────────────┐
│ 正在播放 (标题) │  ──────>      │ [⏮] [▶] [⏭]    │
├─────────────────┤              ├─────────────────┤
│   封面图展示    │              │ 封面图/歌词切换 │
│                 │              │  (点击切换显示) │
├─────────────────┤              ├─────────────────┤
│    播放控制     │              │   进度条等      │
└─────────────────┘              └─────────────────┘
```

**文件**: `lib/features/player/presentation/widgets/now_playing_panel.dart`

---

### 🟠 **高优先级** - 专辑界面优化
减少顶部占用空间，更好展示专辑卡片。

**改动**:
- 顶部控制区从全高缩小到约 1/4
- 专辑卡片更紧凑
- 改进网格布局

**文件**: `lib/features/library/presentation/albums_page.dart`

---

### 🟡 **中优先级** - 资料库界面清理
移除重复元素，简化导航。

**改动**:
- 移除重复的卡片样式
- 保留列表风格
- 简化顶部控制区

**文件**: `lib/features/library/presentation/library_page.dart`

---

### 🟢 **低优先级** - 自定义主题系统
添加高级配置功能。

**改动**:
- 添加颜色配置
- 圆角、间距等参数
- 实时预览

**文件**: 
- `lib/core/storage/library_preferences_repository.dart`
- `lib/features/settings/presentation/settings_page.dart`

## 💾 所需的核心改动

### 1. 扩展 LibraryPreferences
```dart
// 添加字段
final Color customBackgroundColor;
final Color customCardColor;
final Color customPrimaryColor;
final double cardBorderRadius;
final double buttonBorderRadius;
final double componentDensity;
```

### 2. 主题数据模型
```dart
class CustomThemeConfig {
  final Color backgroundColor;
  final Color cardColor;
  final Color primaryColor;
  final Color accentColor;
  final double cardBorderRadius;
  final double buttonBorderRadius;
  // ... 更多
}
```

### 3. 应用主题更新
在 `app.dart` 中使用自定义颜色而不是默认颜色。

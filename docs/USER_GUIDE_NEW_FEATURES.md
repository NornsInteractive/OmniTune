# 使用指南：新增音乐详情菜单和性能优化

## 功能总览

本次更新为音乐列表添加了三项主要改进：

1. ⚡ **性能优化** - 更流畅的大列表滚动
2. 👆 **长按菜单** - 快速访问音乐详情和操作
3. 📋 **详情弹窗** - 查看完整的音乐文件信息

---

## 使用说明

### 访问音乐详情的方式

有**两种**方法打开音乐详情弹窗：

#### 方式 1️⃣：长按歌曲项
在列表中长按任意歌曲卡片：

```
┌─────────────────────────────────┐
│ ♪ Song Title      🔖 ❤️ ⋮      │ ← 长按这里
├─────────────────────────────────┤
│ Artist · Album · Source          │
└─────────────────────────────────┘
         ↓ 长按 ↓
    ✨ 弹窗出现 ✨
```

#### 方式 2️⃣：点击右侧三点按钮
在歌曲项最右侧点击"更多选项"按钮（⋮）：

```
┌─────────────────────────────────┐
│ ♪ Song Title      🔖 ❤️ ⋮      │ ← 点击 ⋮
├─────────────────────────────────┤
│ Artist · Album · Source          │
└─────────────────────────────────┘
         ↓ 点击 ↓
    ✨ 弹窗出现 ✨
```

│ └────────────────────────┘  │

### 各字段说明

| 字段 | 含义 | 示例 |
|------|------|------|
| **文件路径** | 音乐文件在远程服务器上的完整路径 | `/Music/Classical/Chopin/Nocturne.flac` |
| **音源** | 该歌曲来自哪个已保存的音乐源 | `WebDAV - My NAS` |
| **艺术家** | 歌曲的表演者 | `Frédéric Chopin` |
| **专辑** | 歌曲所属的专辑 | `Nocturnes` |

> 💡 **提示**: 所有字段都显示在可读的容器中，便于参考和识别。

## 操作按钮

### 🔖 收藏功能

**按钮状态**:
- 🔖 空心书签 = 未收藏 → 点击添加到收藏
- 🔖 实心书签 = 已收藏 → 点击从收藏移除

**用处**:
- 保存你最喜欢的歌曲
- 在"我的收藏"列表中快速访问

### ❤️ 喜欢功能

**按钮状态**:
- ❤️ 空心心形 = 未标记喜欢 → 点击标记为喜欢
- ❤️ 实心心形 = 已标记喜欢 → 点击取消喜欢

**用处**:
- 标记你正在听的或喜欢的歌曲
- 在"我喜欢"列表中快速访问

## 性能改进说明

### 之前（低效）❌
```
SliverToBoxAdapter
  └─ Column
    └─ 1000 × Row items  ← 全部同时创建和渲染
```
- 内存使用：全部 1000 首歌曲的 widget 树同时存在
- 滚动卡顿：需要维护所有 item 的状态

### 现在（高效）✅
```
SliverList.separated
  └─ itemBuilder(index)  ← 按需创建（虚拟化滚动）
    └─ 只渲染可见的 ~10 项
```
- 内存使用：仅保持可见项的 widget 树
- 滚动流畅：只管理当前屏幕上的 items

### 实际效果
| 歌曲数量 | 之前 | 现在 |
|---------|------|------|
| 100 首 | 流畅 ✅ | 流畅 ✅ |
| 500 首 | 卡顿 ❌ | 流畅 ✅ |
| 1000+ 首 | 很卡 ❌❌ | 流畅 ✅ |

## 操作示例

### 示例 1：快速查看歌曲来源
1. 在"所有歌曲"列表中找到一首歌
2. 长按或点击 ⋮
3. 在"文件路径"和"音源"字段中检查其位置
4. 关闭弹窗

### 示例 2：收藏一首新发现的歌
1. 发现一首好歌
2. 长按打开详情
3. 检查艺术家和专辑信息
4. 点击"添加到收藏"按钮
5. 该歌将出现在"我的收藏"列表中

### 示例 3：标记多首歌为喜欢
1. 打开一首歌的详情弹窗
2. 点击"标记为喜欢"
3. 关闭弹窗（点击外部或向下滑动）
4. 重复对其他歌曲操作
5. 在"我喜欢"列表中查看所有标记的歌曲

## 常见问题

### Q: 怎样关闭详情弹窗？
**A**: 有三种方式：
- 点击弹窗外部（上方）
- 向下滑动弹窗（手势关闭）
- 点击系统返回按钮

### Q: 长按和点击 ⋮ 按钮有区别吗？
**A**: 没有。两种方式都会打开完全相同的详情弹窗，选择你喜欢的方式即可。

### Q: 收藏和喜欢有什么区别？
**A**: 
- **收藏 (Favorites)**: 用于长期保存你最喜欢的歌曲
- **喜欢 (Liked)**: 用于标记当前正在听或最近喜欢的歌曲

两个列表是独立的，一首歌可以既收藏又标记为喜欢。

### Q: 修改收藏/喜欢状态后，其他列表会更新吗？
**A**: 是的。修改会立即同步到：
- 所有歌曲列表（如果该状态改变）
- 对应的集合列表（如"我的收藏"或"我喜欢"）
- 顶部的统计卡片（收藏数和喜欢数会实时更新）

### Q: 大列表滚动卡顿怎么办？
**A**: 
1. 确保应用已更新到最新版本
2. 尝试关闭其他后台应用，释放内存
3. 如果问题持续，请报告 bug（包括设备型号和歌曲数量）

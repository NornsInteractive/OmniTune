# UI 重构工作计划 - v1.0.23+24

## 🎯 需求总结

### 1. 现代极简风格 UI
- 更紧凑的布局
- 减少组件大小
- 移除不必要的元素
- 采用卡片形式

### 2. 自定义配色系统
- 在主题设置中添加自定义配色选项
- 支持配置:
  - 主背景颜色
  - 卡片背景颜色
  - 主题色
  - 其他关键 UI 颜色
- 使用色板选择器

### 3. 主题界面增强
- 卡片圆角大小设置
- 界面大小/密度设置
- 按钮胶囊形大小设置

### 4. 各界面 UI 重做

#### 播放器主界面
- 移除顶部"正在播放"文字
- 封面图和歌词在同一位置
- 点击封面图切换歌词/封面显示
- 播放按钮两侧增加上/下一曲按钮

#### 专辑界面
- 顶部控制区域从占满缩小到约 1/4
- 减小专辑卡片大小
- 更紧凑的布局

#### 资料库界面
- 减小顶部卡片大小
- 移除重复的"所有歌曲/我喜欢/收藏"卡片样式
- 只保留列表样式

---

## 📅 实现步骤

### Phase 1: 主题系统扩展 (1-2 小时)
1. 创建自定义主题配色模型
2. 扩展 LibraryPreferences 存储自定义颜色
3. 在 AppSettingsController 中添加颜色管理方法
4. 创建颜色配置 UI 组件

### Phase 2: 主题设置界面 (1-2 小时)
1. 扩展设置页面添加自定义主题部分
2. 添加圆角、间距等参数设置
3. 实时预览

### Phase 3: 播放器界面重设计 (2-3 小时)
1. 移除顶部文字
2. 实现封面/歌词切换
3. 添加上/下一曲按钮
4. 重新布局组件

### Phase 4: 专辑界面重设计 (1-2 小时)
1. 减小顶部控制区
2. 调整卡片大小
3. 优化布局

### Phase 5: 资料库界面重设计 (1 小时)
1. 移除重复卡片
2. 减小顶部区域
3. 优化列表样式

### Phase 6: 全局样式调整 (1-2 小时)
1. 更新主题配置
2. 调整所有文本大小
3. 调整间距和内边距

### Phase 7: 测试和优化 (1 小时)
1. 各界面测试
2. 主题切换测试
3. 性能优化

---

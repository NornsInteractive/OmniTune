## 🔧 核心代码变更

### 新增文件

#### lib/core/database/library_scan_cache_repository.dart
**职责**: 处理扫描结果的持久化和恢复  
**大小**: ~150 行  
**关键类**:
- `LibraryScanCacheRepository` (抽象接口)
- `JsonFileScanCacheRepository` (JSON 实现)
- `createScanCacheRepository()` (工厂函数)

**主要方法**:
```dart
Future<Map<String, List<LibrarySong>>> loadAllResults()
Future<void> saveScanResults(String sourceId, List<LibrarySong> songs)
Future<List<LibrarySong>> loadScanResults(String sourceId)
Future<void> deleteScanResults(String sourceId)
Future<void> clearAll()
```

#### lib/core/providers/scan_cache_provider.dart
**职责**: 提供缓存实例的 Riverpod provider  
**大小**: ~12 行  
**导出**: `scanCacheRepository` 提供者

### 修改文件

#### lib/core/models/library_song.dart
**变更**: 添加 JSON 序列化  
**新增方法**:
- `Map<String, dynamic> toJson()` - 转换为 JSON
- `factory LibrarySong.fromJson(Map<String, dynamic> json)` - 从 JSON 恢复

#### lib/features/library/application/library_catalog_controller.dart
**变更**: 集成缓存加载和保存  
**修改方法**:
1. `build()` - 启动时加载缓存
2. `scanAllSources()` - 扫描后保存结果
3. `rescanSource()` - 单源扫描后保存结果

**关键代码**:
```dart
// 启动时加载
final cacheRepo = await createScanCacheRepository();
final allResults = await cacheRepo.loadAllResults();

// 扫描后保存
await cacheRepo.saveScanResults(source.id, sourceSongs);
```

#### pubspec.yaml
**新增依赖**:
```yaml
path_provider: ^2.1.3       # 应用缓存目录
shared_preferences: ^2.2.3  # 应用设置存储
```

## 💬 常见问题

### Q: 缓存在哪里存储？
A: 应用私有缓存目录。详见 `SCAN_PERSISTENCE_IMPLEMENTATION.md` 的"缓存存储位置"章节。

### Q: 如何清空缓存？
A: 参考 `SCAN_PERSISTENCE_QUICK_REF.md` 的"清空缓存进行重新扫描"部分。

### Q: 这会影响性能吗？
A: 不会。详见 `v1.0.20_RELEASE_NOTES.md` 的"性能影响"表格。

### Q: 缓存占多少空间？
A: ~50KB / 1000 首歌曲。见 `SCAN_PERSISTENCE_IMPLEMENTATION.md`。

### Q: 支持多设备同步吗？
A: 目前不支持。缓存是本地存储。见 `v1.0.20_RELEASE_NOTES.md` 的"已知限制"。
